## Structural equivalence certification

For matching RNG state, V1.2.7 acceptance tests verify that:

- rootless crossover genome == tree-based flat crossover genome;
- rootless subtree mutation genome == tree-based flat subtree mutation genome;
- rootless point mutation genome == tree-based flat point mutation genome.

The standard speedup therefore does not depend on changing those GP variation decisions.

## Scientific fallback

The rootless hot path is intentionally not used when tree-aware features are required, including constraints, dimensional/unit-aware typed evolution, Semantic GP, memetic search, or evolution-time canonical/algebraic simplification. These workflows keep the safe tree-backed engine.

## gplearn comparison

`examples/benchmark_vs_gplearn.py` is included for an apples-to-apples local comparison. gplearn could not be installed in the isolated build environment because external package access was unavailable. Therefore this acceptance report makes **no unverified universal claim** that V1.2.7 is faster or more accurate than gplearn on all datasets.
