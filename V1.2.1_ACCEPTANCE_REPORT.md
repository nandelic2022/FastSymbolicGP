# FastSymbolicGP V1.2.1 Acceptance Report

## Release identity

- Version: **1.2.1**
- Theme: **Performance Regression Hotfix**
- Primary goal: remove V1.2.0 Python-side evolution overhead without removing V1.2 search/scientific functionality.

## Test matrix

Final source test suite:

```text
104 passed
0 failed
```

The suite includes all historical V1.0–V1.2.0 compatibility, scientific, persistence, performance, publication and search-intelligence tests plus dedicated V1.2.1 performance-hotfix tests.

## V1.2.1 hot-path assertions

Dedicated tests verify that:

- default optimization is scalar;
- default scalar fits make zero NSGA-II ranking calls;
- scalar Pareto reporting is produced with one terminal archive update;
- explicit Pareto search performs one NSGA-II call per completed generation;
- full evolution-state cloning is not performed on every ordinary generation;
- checkpoint generations plus the terminal generation create the required resumable snapshots;
- profiler output exposes `evaluation`, `nsga2`, `pareto_archive`, `state_snapshot`, and `variation` timing.

## API compatibility

- Explicit `optimization="pareto"` remains supported.
- `preset="publication"` explicitly selects Pareto search.
- `get_pareto_front()` and `get_pareto_front_dataframe()` remain available after scalar fits.
- V1.2.0 Semantic GP, age management, memetic search, typed units, constraints, uncertainty, checkpointing, scientific certification and publication tooling remain present.

## Result

**PASS** — V1.2.1 removes the major V1.2.0 performance regression while retaining the certified functional surface.
