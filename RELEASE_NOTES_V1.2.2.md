# FastSymbolicGP V1.2.2 — Fast Variation Engine Hotfix

V1.2.2 fixes the dominant Python-side variation bottleneck observed after V1.2.1 removed the earlier Pareto/NSGA-II overhead.

## Main changes

- zero-copy standard tournament selection;
- bulk tournament schedules for the common scalar/tournament path;
- persistent-tree structural sharing during crossover and mutation;
- immutable cached program paths;
- single-pass program size/depth calculation;
- fast depth/node admissibility checks for ordinary non-typed, non-hard-constrained GP;
- cheap internal evolution snapshots;
- removal of the sklearn DataFrame feature-name warning generated by internal validation;
- dedicated V1.2.2 regression/performance tests.

## Reference benchmark

After a Numba warm-up, the bundled runtime completed the 500-population × 100-generation Diabetes benchmark with `add/sub/mul/div`, depth 8, nodes 60, scalar optimization and fused Numba fitness in about 10.1 seconds. Stage timing was approximately 4.7 s variation and 4.8 s evaluation. Results are hardware/runtime specific.
